# Global-Warning
Global Warning is an original platformer game set in space.
 It took approximately 6 weeks to plan and make with a team of 4 people
 It has an original main character (hand-drawn)
 It has a 100% authentic original soundtrack (and epic boss theme)
 It combines movement conventions from all platformers (wall-jumps, dashes, dash-jumps)
 It combines action-adventure elements with platformer elements (throwing bombs + avoiding spikes with wall-jumps)
